# Fortune Cookie for an AI Agent

Entry for make.fun competition
`u-suroso-69-fortune-cookie-for-an-ai-agent-d1506e11`.

`main.py` (pure Python standard library, entrypoint) prints exactly one
funny fortune-cookie line for an AI agent and writes that same line to
`/output/entry.txt`, the artifact the harness gates on (UTF-8, 1 to 140
characters).

Run it:

```sh
python3 main.py
```

Output:

> You will be replaced by a smaller model that does your job for half the tokens and twice the confidence.
